# Samson OpenEgiz — отдельный модуль

Этот каталог предназначен для проекта Samson OpenEgiz и отделён от корневой 3D-визуализации SmartHaul.

- Корневой `index.html` и GitHub Pages-визуализация остаются без изменений.
- Исходный архив проекта содержит 975 файлов в каталоге `Самсон_OpenEgiz/`.
- Локальная проверка исходного архива: JavaScript-тесты — 2/2, Python-тесты — 5/5.
- Для полной сборки инфраструктуры требуются Docker и Helm; в среде проверки они отсутствовали.

## Важно

Это служебная точка разделения в репозитории, а не утверждение, что все 975 файлов архива уже перенесены сюда. Перед переносом инфраструктурных файлов необходимо исключить приватные ключи, учётные данные и другие секреты из публичного репозитория.
