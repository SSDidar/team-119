# SmartHaul — цифровой карьер на OpenEgiz

Интерактивный демонстрационный стенд диспетчеризации карьера: обзор уступов и маршрутов, движение условного парка самосвалов, очередь, перекрытие дороги C-3 и отказ отдельной машины.

## Быстрый запуск визуализации

Откройте `index.html` в Chrome или Edge. Внешние библиотеки, npm и сервер для этой автономной демонстрации не нужны.

- Нажмите сценарии справа или кнопки «Назад / Далее».
- `← / →` переключают сцены, `Пробел` — пауза/продолжение, `R` — сброс.
- Перетаскивайте мышью сцену, колесом меняйте масштаб.

## Сценарии

1. Обзор цифрового карьера.
2. Цикл самосвала.
3. Очередь на погрузке.
4. Перекрытие сегмента C-3 и альтернативный маршрут.
5. Остановка HT-04 при продолжающемся движении остальных машин.
6. Сравнение состояния сети.

**Важно:** HTML — автономный презентационный прототип. Его показатели синтетические, не являются реальной телеметрией и не подтверждают экономический эффект. Эта страница сама по себе не подключается к MQTT/Eclipse Ditto и не управляет реальным оборудованием.

## OpenEgiz platform

В репозитории сохранены исходные файлы платформы и примера. Базовый запуск платформы описан в [OPENEGIZ.md](OPENEGIZ.md). В чистой среде с Docker и make можно использовать:

```bash
make up
make example-mine
```

Следуйте текущим требованиям и инструкциям платформы в [OPENEGIZ.md](OPENEGIZ.md) и [OPENEGIZ.ru.md](OPENEGIZ.ru.md). Для работы полноценного стенда требуется проверить совместимость сервисов и конфигурацию конкретного окружения.

## Структура

- `index.html` — автономная интерактивная визуализация SmartHaul.
- `SUBMISSION.md` — описание конкурсной концепции, сценариев и ограничений.
- `TECHNICAL_AUDIT.md` — технический аудит прототипа и статус проверок.
- `QA_REPORT.md` — ручной/статический чек-лист; не заменяет запуск тестов в целевом окружении.
- `examples/mine/` — пример цифрового карьера платформы.

## Статус и ограничения

Прототип демонстрирует интерфейс и сценарии, но не является производственной системой диспетчеризации. Не используйте его для управления реальной техникой или принятия решений по промышленной безопасности. Интеграцию с OpenEgiz, передачу телеметрии и воспроизводимые тесты платформы нужно валидировать отдельно.
